# AI Rap Video Prompt Pack

Open-source markdown prompts synced with https://ai-rap-video.wiki — every wiki template ships here as a plain .md file, generated from the same source of truth.

## What's inside

12 files, one per wiki template. Each contains: intent, when to use, the copy-ready main prompt, beat and camera notes, the negative prompt block, photo prep, tool-agnostic render steps, failure modes, and the compliance note.

## How to use

1. Grab the files — clone this repo or download `pack/`.
2. Start with `ai-rap-video-duo-prompt.md` (two people) or `ai-rap-video-self-duo-two-outfits.md` (just you).
3. Copy the main prompt block, replace the bracketed placeholders, keep everything else.
4. Render in any Wan-style or Seedance-style image-to-video tool — the steps section is tool-agnostic.
5. Keep the compliance note. It travels with each file on purpose.

## See the format in motion

The wiki pairs every template with real video examples embedded from YouTube — trend explainers, full workflow tutorials, and Wan/Seedance deep dives: https://ai-rap-video.wiki/examples/

## Rules

- Original staging and lyrics descriptions only
- Do not commercially bind protected Hotel Lobby recordings or celebrity faces
- Consent from every face you render
- Not a paid generator: the templates are the free prompt method — pair them with any image-to-video model you already use (see the wiki's generator comparison)
